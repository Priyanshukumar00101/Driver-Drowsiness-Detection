# 😴 Driver Drowsiness Detection System

A real-time Driver Drowsiness Detection System developed using **Python**, **OpenCV**, and **Computer Vision** techniques.  
The system monitors the driver's eyes continuously and triggers an alert whenever drowsiness is detected to help prevent road accidents.

---

# 🚀 Features

✅ Real-time face and eye detection  
✅ Detects eye closure and drowsiness  
✅ Alert system for driver safety  
✅ Computer Vision based implementation  
✅ Lightweight and efficient project  

---

# 🛠️ Tech Stack

- Python
- OpenCV
- NumPy
- Computer Vision

---

# 📸 How It Works

1. Captures live video using webcam
2. Detects driver's face and eyes
3. Monitors eye movement and blinking
4. Triggers alert if eyes remain closed for long duration

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Priyanshukumar00101/Driver-Drowsiness-Detection.git
```

Move into project directory:

```bash
cd Driver-Drowsiness-Detection
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
